| [bin/ai/ai-sandbox-lib.sh](file:///home/jlewandowski/dev/public/dev-tools/bin/ai/ai-sandbox-lib.sh) | Shared bash library, sourced by `create-ai-sandbox.sh` and every `ai-sandbox-*` command: path-derived project identity, sandbox paths, compose invocation, the shared-mount and credential-seed tables, and the image build hash. Also the install root (`AI_SANDBOX_INSTALLED`), `ai_sandbox_refuse_writable_self` (the refusal of every host entry point), `ai_sandbox_write_bashrc_block` and `ai_sandbox_mounts_install_root`.
