# Decisions

Why each rule exists, one entry per integrated or rejected proposal, newest first.
The integrator appends here in the same commit that changes `rules/`, `roles/` or
`skills/`, so a later reader can tell a deliberate rule from an accident and an
agent can see that a rejected idea was already considered.

Format:

```
- YYYY-MM-DD <proposal file name without extension> integrated | rejected
  <target file or "none">: <one or two sentences on why>
```
